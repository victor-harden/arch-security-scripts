# 🔐 Arch Security Scripts

Collection of practical hardening, privacy and monitoring scripts for Arch Linux.

## Scripts included

| Script | Description |
|--------|-------------|
| `firewall-setup.sh` | Configure strict nftables rules |
| `privacy-toggle.sh` | MAC randomization + DNS privacy |
| `update-checker.sh` | Check for security updates |
| `clamav-scan.sh` | Automated malware scan |
| `hardening-check.sh` | Verify current hardening status |

## Usage

```bash
chmod +x *.sh
sudo ./firewall-setup.sh
```

## Requirements

- Arch Linux
- Root privileges for most scripts
